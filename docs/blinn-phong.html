Blinn-Phong

Blinn-Phong 是对 lighting 一节里 Phong 模型的一点调整。 它给出更可信、也更真实的 specular reflection。 你会注意到 Blinn-Phong 产生的 specular reflection 是椭圆或被拉长的， 而 Phong 模型产生的是球形 specular reflection。 在某些情况下，Blinn-Phong 比 Phong 算起来更省。

  // ...

  vec3 light   = normal(lightPosition.xyz - vertexPosition.xyz);
  vec3 eye     = normalize(-vertexPosition.xyz);
  vec3 halfway = normalize(light + eye);

  // ...

不再计算 reflection vector， 而是计算 halfway，也就是半角 vector。 这个 vector 位于 view、camera、eye 方向和 light 方向之间。

    // ...

    float specularIntensity = dot(normal, halfway);

    // ...

现在 specular 强度是 normal 和 halfway vector 的点积。 在 Phong 模型里，它是 reflection vector 和 view vector 的点积。

当 view vector（橙色箭头）和 reflection vector（洋红色箭头）同向时， 半角 vector（洋红色箭头）会和 normal（绿色箭头）同向。 这时 Blinn-Phong 和 Phong 的 specular 强度都是 1。

在其他情况下，Blinn-Phong 的 specular 强度会大于 0， 而 Phong 的 specular 强度是 0。
