3D Game Shaders For Beginners

想给你的 3D 游戏加上 texture、 lighting、 shadow、 normal map、 发光物体、 ambient occlusion、 reflection、 refraction， 以及其他效果吗？ 很好！ 下面是一组 shading 技术，可以把画面再推高一层。 每一种技术我都讲到你可以把这里学到的东西应用或移植到 你正在用的技术栈，无论是 Godot、Unity、Unreal，还是别的引擎。 shader 之间的胶水层， 我选了出色的 Panda3D game engine 和 OpenGL Shading Language (GLSL)。 如果你用的正是这套技术栈，你还会具体学到如何在 Panda3D 和 OpenGL 里使用这些 shading 技术。
