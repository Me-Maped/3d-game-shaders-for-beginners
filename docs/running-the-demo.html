3D Game Shaders For Beginners

运行 Demo

示例代码构建完成之后，就可以运行可执行文件，也就是 demo。

./3d-game-shaders-for-beginners

在 Linux 或 Mac 上这样运行。

3d-game-shaders-for-beginners.exe

在 Windows 上这样运行。

Demo 操作

Demo 同时提供键盘和鼠标操作，用来移动 camera、 开关各种效果、 调整 fog， 以及查看不同的 framebuffer texture。

鼠标

按住 Left Mouse 拖动可以旋转场景。 按住 Right Mouse 拖动可以上下左右移动。 Mouse Wheel 向前滚是拉近。 Mouse Wheel 向后滚是拉远。

也可以用鼠标改变焦点。 要改变焦点， 用 Middle Mouse 点击场景中的任意位置。

键盘

  • w 让场景向下旋转。
  • a 让场景顺时针旋转。
  • s 让场景向上旋转。
  • d 让场景逆时针旋转。
  • z 拉近场景。
  • x 拉远场景。
  • ⬅ 向左移动。
  • ➡ 向右移动。
  • ⬆ 向上移动。
  • ⬇ 向下移动。

  • 1 显示正午。
  • 2 显示午夜。

  • Delete 开关声音。
  • 3 开关 fresnel。
  • 4 开关 rim lighting。
  • 5 开关粒子。
  • 6 开关 motion blur。
  • 7 开关 Kuwahara filtering。
  • 8 开关 cel shading。
  • 9 开关 lookup table 处理。
  • 0 在 Phong 和 Blinn-Phong 之间切换。
  • y 开关 SSAO。
  • u 开关 outlining。
  • i 开关 bloom。
  • o 开关 normal mapping。
  • p 开关 fog。
  • h 开关 depth of field。
  • j 开关 posterization。
  • k 开关 pixelization。
  • l 开关 sharpen。
  • n 开关 film grain。
  • m 开关 screen space reflection。
  • , 开关 screen space refraction。
  • . 开关 flow mapping。
  • / 开关太阳动画。
  • \ 开关 chromatic aberration。

  • r 重置场景。

  • [ 减小 fog 的 near 距离。
  • Shift+[ 增大 fog 的 near 距离。
  • ] 增大 fog 的 far 距离。
  • Shift+] 减小 fog 的 far 距离。

  • Shift+- 减少 foam 的量。
  • - 增加 foam 的量。

  • Shift+= 减小相对 refraction index。
  • = 增大相对 refraction index。

  • Tab 向前切换 framebuffer texture。
  • Shift+Tab 向后切换 framebuffer texture。
